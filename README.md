
# ElectroShop Pro

## Возможности
- Корзина
- Оформление заказа
- Админ-панель
- Каталог с фильтрами
- Тёмная тема
- Анимации
- Адаптивный дизайн
- React / Next.js frontend
- Node.js backend API

## Запуск Frontend
cd frontend
npm install
npm run dev

## Запуск Backend
cd backend
npm install
npm start
